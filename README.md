# Humidor Journal

A cigar journal: log the cigars you smoke, note what you enjoyed, and get personal recommendations.

- `index.html` — the app
- `catalog.js` — the cigar vault (brands, blends, strength, flavor notes)
- `serve.ps1` — runs the app locally at http://localhost:8080 for testing

To test on this PC:

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
